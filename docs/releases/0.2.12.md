# Sector 0.2.12

Sector brings Active Reset and ten customizable telemetry widgets to Le Mans
Ultimate. This release includes the portable Windows app: no separate Python,
Node.js or installer is needed.

## Download and start

1. Download **Sector-0.2.12-win-x64.zip** from the assets below.
2. Extract the whole ZIP and open **Sector.exe** in the extracted folder.
3. Confirm the LMU installation folder and optionally start the guided tour.
4. For Active Reset, launch LMU without EAC, choose **Offline → Practice** and
   enter **DRIVE**. Save a healthy car with **F6**, wait for confirmation and
   restore with **F7**.

Use windowed or borderless mode for overlays. Enable widgets in **Overlay**,
arrange them with **Edit layout**, then select **Lock layout**.

## Included

- Checkpoint save and restore with configurable keys and confirmation sounds.
- Home page with game launch, session information and checkpoint actions.
- Leaderboard, Relative, Weather, Delta, Inputs, Laps, Session, Tyres,
  Stint planner and Hybrid widgets.
- Customizable positions, sizes, opacity, columns, logos and display selection.
- First-launch setup, in-app guide, changelog and background mode.

## Latest changes

- Overlay updates follow the selected monitor's refresh rate, including
  fractional rates. Changing monitors does not restart the telemetry reader.
- Pausing LMU hides widgets promptly. A short telemetry timeout handles cases
  where the game does not publish a pause signal.
- F7 keeps the last overlay frame visible until fresh telemetry arrives,
  while clearing the histories affected by a reset.
- Leaderboard and Relative update estimated gaps between scoring samples.
  Estimated values are marked with `~`.
- The healthy-save check no longer mistakes a render flag for vehicle damage.
  A live Mercedes-AMG LMGT3 trial confirmed visible front bodywork repair.

## Compatibility and current limits

Active Reset requires Offline Practice without EAC and the verified LMU Steam
build **25661166** (game build **14200**). Sector checks compatibility before
connecting; a later game update may require a Sector update.

Damage repair is experimental. Save a healthy car and restore after the impact
has ended. Other cars and impact types still require testing; punctures and
detached parts are not supported. Checkpoints belong to the current car/session
and do not persist across game restarts.

Telemetry availability varies by car and game state. Flat spots, intermediate
gaps and consumption-based predictions are estimates. Hybrid suggestions require
observed laps and do not adjust the car's map automatically.

The display synchronization and pause/F7 visibility changes passed automated
tests, including native overlay windows. Their live-game visibility check is
still pending. See the [verification record](https://github.com/sector-lmu/Sector/blob/v0.2.12/docs/TEST_RESULTS.md).

## Updating

Choose **Quit Sector** in the old version before starting this one. Extract into
a new folder, keep all package files together and update your shortcut. Existing
preferences and layouts are retained. Restart LMU if Sector requests it.

The download is unsigned. `SHA256SUMS.txt` contains the Windows ZIP checksum.
