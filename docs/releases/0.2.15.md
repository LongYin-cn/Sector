# Sector 0.2.15 Experimental

**Experimental pre-release. Bugs remain possible and further fixes are planned.**

## Changes

- Fix the reported F6 refusal `92004 / component_count = 0`: a stable model
  without deformable bodywork components is now a valid checkpoint.
- Keep full bodywork restoration for models with components, plus loading,
  topology, lifetime and memory checks for both representations.
- Verify fuel consumption and tyre wear enabled or disabled, including fresh
  and already worn tyres. Sector restores saved values without changing the
  game's damage, fuel or tyre settings.
- Include the v24 reset module and the existing diagnostic export system.

## Install and test

1. Download `Sector-0.2.15-win-x64.zip` and extract the entire folder.
2. Quit the previous Sector version completely and restart LMU, then open the
   new `Sector.exe`. An older reset module remains resident until LMU exits.
3. For Active Reset, use **Offline > Practice without EAC**. Enter DRIVE with a
   healthy car, press F6 once and wait for **Checkpoint saved**.
4. Move away and press F7 once. Repeat in a new Practice with damage, fuel
   consumption and tyre wear set as desired. Save a fresh checkpoint each time.
5. If a command fails, use **Help > Export diagnostics > Save diagnostic file**
   and include the car and session settings with the JSON.

The native fixture verifies complete physical restore with empty and populated
bodywork models. Numerical regression tests cover eight fuel/tyre state
combinations. These are automated checks; the affected user's PC still needs
the live F6/F7 confirmation. Damage repair remains experimental: punctures and
detached parts are not supported. Wait until an impact ends before restoring.

This release is published from `dev`; `prod` and the latest stable release
remain at 0.2.12. Online overlays use the public SDK; Active Reset stays offline.
