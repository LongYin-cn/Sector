# Sector 0.2.14 Experimental

**Experimental pre-release. Bugs are expected and further fixes are planned.**
Use this build to collect diagnostics for unsupported bodywork and other app
errors. It does not yet fix the reported 92004 bodywork refusal.

## Changes

- Add **Help → Export diagnostics** to save one shareable JSON file.
- Record the exact bodywork layout check, component, mesh, flags and observed
  limits behind error 92004, using the new v23 reset module.
- Include recent reset reports, app state changes, graphics/system versions and
  available vehicle/track context. Exclude raw memory and physics captures.
- Bound exported log size and mask Windows user-directory names. No automatic upload.
- Include the 0.2.13 setup dialog improvements and independent public SDK
  discovery for online overlays. Live online/EAC verification remains pending.

## Install and send a diagnostic file

1. Download `Sector-0.2.14-win-x64.zip` and extract the whole folder.
2. Close the previous Sector with **Quit Sector** and restart LMU to unload the
   older reset module. Open the new `Sector.exe`.
3. For the bodywork test, launch LMU without EAC, enter Offline Practice and DRIVE
   with the same car/settings that produced the error. Reproduce it once.
4. Open **Help → Export diagnostics → Save diagnostic file**. Save the JSON and
   send it with the car model and whether F6 or F7 produced the error.

For online overlays, launch LMU normally with EAC; Active Reset stays unavailable.

## Known limits

Bodywork restoration remains experimental. GPU-mapped buffers, punctures and
detached parts are unsupported. Only the previously tested Mercedes-AMG LMGT3
front-bodywork case has live confirmation; other cars/configurations can refuse
a save or restore. This build has automated fixture coverage, not live validation
on the affected user's PC. Do not treat it as a general bodywork compatibility fix.

The production branch and latest stable release remain at 0.2.12.
